# Week 22 — The First Pass

## Novels are rewritten, not written

The draft is raw material. The book is made in revision. Expect multiple passes, and run them in layers from largest to smallest. The cardinal rule: never line-edit a scene you might cut. Fixing commas in a chapter you'll delete is wasted work. Structure first, sentences last.

## The structural pass

Start with the biggest question: does the whole thing work? Read the full draft straight through, taking notes without editing, so you see the macro problems. Then interrogate the big elements. Is the protagonist's arc complete and earned? Does the plot escalate, or does it plateau? Are the stakes clear and rising? Does every scene justify its existence? Are there plot holes, saggy stretches, unmotivated actions, an unearned ending? This pass can mean cutting characters, adding scenes, restructuring acts, or rewriting the ending. Do it before you touch the prose.

## The scene pass

Next, work scene by scene. Does each scene have a POV goal, a conflict, and a turn? Does it enter late and leave early? Does it advance the plot and reveal character? Is it in the right place? Cut scenes that only repeat information or spin without turning. Combine scenes that do the same work. Make sure each connects to the next by cause and effect, therefore and but, not and then. This is still structural work, still done before line-level polish.

## Task

Read your pages straight through, taking notes without fixing anything, to see the whole shape. Then run the structural pass against the big questions, and the scene pass against every scene. Fix structure and scenes before you touch a single sentence.
